# Space Chords

Interactive website for exploring musical chords. 

<b>Controls:</b>
* WASD - Fly spaceship
* Space - Toggle current instrument on/off
* Right/left arrow keys - Change current instrument
* Move mouse - Change parameters of instrument

### Chord Discovery

As you fly a spaceship around the map, each new spot you visit will play a new chord. Revisiting the same spot will play the same chord associated with that spot. The boundaries for these "spots" are hidden, but underlying the entire map is made up of connected hexogonal tiles.

> <b>Planets</b> <br>
> Planets are spots on the map where the game decides on a specific chord to associate with that spot before it decides on the neighboring chords. Planets can have these chord types:
> * Tonic
> * Secondary dominant
> * Parallel minor
> * Neighbor key
> * Evil

When the game first loads, it places tonic planet at the center tile, and a few random planets near the player. To pick what chords play on nearby tiles to the player, the program runs this algorithm for each tile:
1. Runs a breadth-first-search from the tile to find the nearest planet.
2. For each tile in the path from the closest planet, goes through the list of all possible chords and picks one that would voice-lead (musical term for transition) well from the previous tile's chord.

As you explore the map, more planets will appear.

### Visual Effects

The vibe of the current chord being played will determine the visual environment:
* <b>Tonic:</b> Yellow background and fireworks
* <b>Peaceful:</b> Green background and wind
* <b>Melancholy:</b> Blue background and rain
* <b>Evil:</b> Red background and lightning
* <b>Dark:</b> Black background

### Sound Design

While roaming the map, you can also control what the music sounds like. There are three instruments that can be tweaked in real time by moving the mouse and toggled on/off with the spacebar:

<b>Chords:</b> Polyphonic synth that sustains the current chord (parameters can be cycled between primary and secondary using up/down arrow keys)
* <b>Mouse X:</b> Cutoff of low-pass filter
* <b>Mouse Y:</b> Resonance of low-pass filter
* <b>Secondary Mouse X:</b> LFO Rate
* <b>Secondary Mouse Y:</b> LFO Depth

<b>Arpeggiator:</b> Monophonic synth that arpeggiates through the current chord
* <b>Mouse X:</b> Cutoff of low-pass filter
* <b>Mouse Y:</b> Decay time of volume envelope

<b>Kick:</b> Kick drum that plays on every beat
* <b>Mouse X:</b> Sidechain compression amount (how much the volume of the chords and arpeggiator duck when then kick plays)
* <b>Mouse Y:</b> Tempo (applies to the tempo of the arpeggiator as well)

## Process

My primary goal for this project was to create some interactive experience for exploring chord progressions, hopefully allowing the player to hear cool and compelling sounding music. 

### Chord Discovery

My first idea was to group chord types into "biomes" around a map, such as happy, sad, and evil biomes where if you entered those regions it would play chords accordingly. My first prototype had three circular regions, melancholy, serene, and evil, each with 6 slices that each had a chord. While some of these chords sounded cool and compelling, their assignment into those specific regions didn't make sense sometimes. I soon realized that assigning chords to distinct regions that reprented moods was actually more ambiguous than I thought, because in reality the mood of a chord is evoked by its relationship to other chords before and after it. In addition, this current prototype was limited to just these 18 chords.

In my second prototype, I assigned each chord to a hexogonal tile, so that way the map could be an infinite expanse of hexagonal tiles with no gaps in between. To make the transitions smooth between each chord, I ditched the biome idea temporarily and instead just make each tile's chord the chord that would voice-lead the best to the chords around it. This worked, although certain chords that I wanted to hear often only showed up once, such as the starting tonic chord. To solve this, I made the game spawn multiple tonic chords around the map, and then fill in the gaps with all the other chords. I later made these "landmark" chords include other chord types in addition to tonic, so that those other chord types could be more common as well. Each chord in between these landmark chords was now generated by just mutating the nearest landmark chord a certain amount of times. This worked, but most of the chords didn't sound very interesting. To solve this, I decided to hard-code all the chords that could be played beforehand instead of having the program generate them. With the assistance of Claude, I made a list of 73 total possible chords across the function categories of tonic, parallel minor, secondary dominant, and neighbor key, as well as vibe categories of peaceful, melancholy, dark, and evil. I then made it so that instead of generating a chord, the program decides on the most similar chord in the list of possible chords. I also made a separate interface that I could use to manually assign scores to the transitions between each chord, so that the program is better trained to make transitions sound good.

### Visual Effects

In my first prototype, I liked how, because of the empty space, the whole screen could change to a whole different color based on the mood of the current chord. However, once I switched to the tile-based layout, the entire screen was filled with tiles, and so this was abandoned for now.

In the tile-based layout, I tried adding visual indicators of how each neighboring chord would function by assigning them a color based on whether they would resolve, give tension, etc. I also made some tile connections thick edges to indicate that that transition would be a big jump. However, these two things didn't really line up with what I was hearing and so they just felt kind of random. I also included a minimap of all the landmark chords. 

<img width="1632" height="877" alt="image" src="https://github.com/user-attachments/assets/cc0e0c56-386d-47ec-b745-ed124da70e41" />


This tile layout still felt really boring and not very exciting. I brainstormed different ideas for what the game could look like visually, including an isometric 3D view and pixel art. However, I eventually settled on just trying to simplify my current setup. The first thing I did was hide the tiles all together, which actually made the game a lot more engaging because there was a feeling of mystery for what any spot ahead of you will sound like. At this point I got the idea to make it sort of space-themed, since flying around in a vast black space is just like space. Given this, I turned the landmark chords into planets that had gravity. I also added stars in the background. For the effects that go with certain chord types, I wanted them to be dramatic, so I made the color of the whole screen change and added effects like lightning and rain. These effects weren't very space-like but it made it more interesting nonetheless.

Each effect has an algorithm generated by Claude that outputs an array of particles to render for each frame. 

### Sound Design

The website uses the Web Audio API to both synthesize instruments and play samples (kick).

The very first synth sound Claude generated for me to play the chords actually sounded pretty nice, and so I stuck with that for a while. I made the pitch glide from chord to chord so that transitions would sound cooler and more smooth. However, at a certain point I wanted to experiment with the sound to see if it could sound even cooler. I started by syncing up the website to Ableton Live on my computer via MIDI so that I could control software synths such as Vital. I realized that this sounded a lot more exciting than the built-in sound the website had. I added two more instruments to this Ableton session, an arpeggiator and a kick, which made it sound even cooler. Eventually I realized that it would be clunky to require Ableton set up to use this website, so I began trying to implement the instruments I had setup in the Ableton session into the website directly. Now, I have three instruments directly in the website with parameters I can tweak live, just like what was going on in my Ableton session.
